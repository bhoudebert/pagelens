Station 00 · The problem

Words are not the whole manual

Technical PDFs show their parts: photos, scans, vector drawings, small icons inside large layouts. Keyword search only sees the text layer, so an unlabelled picture of a pump, or a scanned page with no text at all, is invisible to it.

Typical PDF search

Matches words. Misses image-only scans. Returns a whole document. A similarity score is treated as the answer.

Pagelens

Matches what is depicted. Returns document, page, region and preview. A vision model can confirm or reject each candidate and say which kind of evidence it used.

Private by design

PDFs and crops stay local. Models run through Ollama on your hardware. After the first model pull, it works offline.

Measured

Ships page-level ground truth and an evaluate command, so every change is scored, including false confirmations.

Station 01 · The production line

From PDF to evidence in four stations

Indexing is an assembly line. Each station does one job and hands the part to the next. Every region keeps its provenance: source file, page, bounding box and preview.

01
RenderPyMuPDF rasterises each page at 144 dpi, so vector drawings count too.
02
TileOverlapping 768 px regions (128 px overlap). Text blocks that touch a region attach to it. OCR fills in scanned pages if Tesseract exists.
03
EmbedOllama embeddinggemma-2 puts text and images into one 768-d vector space.
04
StoreSQLite keeps normalised vectors, text, provenance and an FTS5 index. Re-ingesting replaces, never duplicates.

Then the inspection line

A
EncodeQuery text and each reference image become separate vectors. Views are kept apart, not averaged.
B
ScoreEach region gets its best cosine similarity across query vectors, plus a small boost for exact-text matches.
C
GroupThe strongest region per PDF page is kept as that page's evidence.
QC
Verify (optional)Qwen3-VL sees the crop and the full page, then returns confirmed, rejected or uncertain, plus metadata.
Station 02 · Commissioning

Fire it up in five minutes

You need Python 3.11–3.13 and Ollama 0.12.7 or newer. Tesseract is optional and only reads text from scanned pages.

  1. Pull the models (one time, about 7 GB).
    shell
    ollama pull embeddinggemma-2:440m-q8_0-text-vision   # retrieval
ollama pull qwen3-vl:8b-instruct                      # optional verification
  2. Install the CLI.
    shell
    pip install -e .      # or: uv sync
  3. Run the demo on four fictional manuals.
    shell
    scripts/demo.sh --verify
  4. Point it at your own PDFs.
    shell
    pagelens init
pagelens ingest ./manuals
pagelens query "industrial water pump"
pagelens query --image ./photo-of-the-part.jpg
pagelens query "same pump" --image ./photo.jpg --verify
pagelens query "AF-P-1042" --json
Using Nix? Mind the double dash. Write nix run path:. -- query "motorcycle" --verify. Without --, Nix reads --verify as its own option and stops with unrecognised flag. Or run nix shell path:. once and call pagelens directly.

Station 03 · Quality control

Every change gets scored

testdata/ holds four fictional manuals with page-level ground truth: labelled objects, an image-only scan, a text-only procedure, a vector drawing, a small object in a large layout, and deliberate hard negatives (a fuel pump, a compressor, a radiator).

shell
pagelens evaluate testdata/ground-truth.json            # candidate recall
pagelens evaluate testdata/ground-truth.json --verify   # + false-confirmation checks
pagelens evaluate testdata/ground-truth.json --scenario motorcycle-visual

Honest result. The stricter --verify run currently flags one known failure: with --evidence any, the vision model confirms the radiator page (service-bulletin.pdf p. 1) for the reference AF-P-1042, which it does not contain. The harness exists to surface exactly this kind of regression.

Evaluation exits non-zero when any scenario fails, so it drops straight into CI. Write your own ground-truth file in the same shape: queries[] with relevant and must_not_confirm PDF/page pairs.

Recipe 1 · A new embedder

Satisfy the protocol: a model_id, and two methods returning L2-normalised float32 arrays of shape (n, dim). Text and image vectors must share a space.

src/pagelens/adapters/embedding_myclip.py
from collections.abc import Sequence
from pathlib import Path

import numpy as np
from pagelens.domain.models import FloatArray


class MyClipEmbedder:
    model_id = "my-clip-v1"   # stored with the index; changing it means re-ingesting

    def embed_texts(self, texts: Sequence[str]) -> FloatArray:
        vectors = self._encode_text(list(texts))
        return _unit(vectors)

    def embed_images(self, images: Sequence[Path]) -> FloatArray:
        vectors = self._encode_images([p.read_bytes() for p in images])
        return _unit(vectors)


def _unit(v: FloatArray) -> FloatArray:
    norms = np.linalg.norm(v, axis=1, keepdims=True)
    return (v / np.maximum(norms, 1e-12)).astype(np.float32)

Then use it in cli.py where OllamaMultimodalEmbedder(...) is built. Import heavy model packages lazily inside the class, not at module import time.

The rules of the shop floor

  • Business rules live in application/; provider code behind protocols in ports.py.
  • Unit tests are offline and deterministic: temporary PDFs, fake embedders, no Ollama.
  • Python 3.11+, full type annotations (mypy --strict), Ruff formats everything.
  • User-visible changes update CHANGELOG.md; requirement changes update openspec/.
  • Never commit customer PDFs, weights, previews or indexes. The fictional testdata/ PDFs are the only exception.

Bonus station · The toolbox

How Nix builds and runs it

Nix is optional, but it gives every user and every CI machine the exact same toolchain. Think of it as a factory that builds each part from a fully specified recipe, files the result by the hash of its inputs, and never mixes parts from different batches.

Reading nix run path:. -- query …

PieceMeaning
nix runBuild a program from a flake and execute it. Nothing is installed globally; results live in /nix/store and are cached.
path:.The flake reference: the current folder, read as plain files. Without path: Nix assumes a git repository and ignores untracked files.
--Everything before it is for Nix, everything after goes to Pagelens. Without it, --verify is read as a Nix option and fails.
#qualityOptional. Picks a named app instead of the default, for example nix run path:.#quality.

What gets built

packages.default (nix/modules/package.nix) uses buildPythonApplication. It produces a store path whose bin/pagelens is a wrapper that points at a pinned Python 3.12 and exact store paths for numpy, pymupdf, typer and the rest. Each dependency is its own hashed directory; nothing touches your system Python.

lib.getExe turns that package into the path of its main executable, using meta.mainProgram. In nix/modules/apps.nix, default.program = lib.getExe config.packages.default is what nix run path:. executes.

nix/modules/apps.nix (excerpt)
apps = {
  default = {
    type = "app";
    program = lib.getExe config.packages.default;   # …/bin/pagelens
  };
  quality = pythonApp "pagelens-quality" "scripts/quality.py" "Run all quality checks";
};
Two flavours of Python. The installable app contains Pagelens itself. The quality app and dev shell use pagelensPython, an interpreter with libraries plus pytest and mypy, and add your working tree through PYTHONPATH, so tests always run your current edits.

A dendritic flake

flake.nix is only a few lines. It hands the folder nix/modules/ to import-tree, which loads every file as a flake-parts module. Add a capability by dropping in a file; nothing needs registering.

Command cheat sheet

CommandWhat it does

What Nix does not bundle. Ollama and its models run as a separate server that Pagelens talks to over HTTP. Tesseract is part of the dev shell and the quality app, but not of the installed app's wrapper, so OCR in nix run path:. -- ingest needs Tesseract on your own PATH. Visual retrieval works without it.
Station 05 · Known limits and roadmap

Honest about the edges

AreaLimit
VerificationWith --evidence any the vision model can confirm a page that does not contain the requested reference. Treat confirmed as strong evidence, not proof.
ScaleBrute-force search over all vectors in SQLite. Good for thousands of pages, not millions.
RankingCosine plus a small lexical boost. Not calibrated probabilities.
Small objectsThings much smaller than a tile can be diluted. Try a smaller tile size and re-ingest.
IdentityLook-alike products can score high. Similarity is not identity.
OperationsSingle user, single writer, no auth, no service API.

Roadmap

  1. Approximate nearest neighbours behind RegionStore (Qdrant or sqlite-vec).
  2. Incremental ingestion that skips unchanged files by content hash.
  3. Stronger verification: few-shot prompts and a second opinion for text evidence.
  4. Layout-aware regions for figures and tables.
  5. A local viewer that highlights the bounding box on the page.
  6. Learned reranking, then an authenticated HTTP service mode.
