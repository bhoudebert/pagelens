# Specifications

`specs/<capability>/spec.md` describes what the system does today, as requirements with
scenarios. `changes/` holds proposals that add or modify requirements before they are
implemented; once merged into the code, a change is folded into the specs and its folder
moves to `changes/archive/` (dated).

| Capability | Covers |
| --- | --- |
| multimodal-pdf-search | PDF ingestion, text and image retrieval, grounded results, optional verification, evaluation |
