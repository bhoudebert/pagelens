# Support

- **Something broken**: open a bug report with the issue template. Include
  `pagelens --version`, `pagelens status`, and the Ollama models in use (`ollama list`).
  Use fictional or public PDFs; never attach confidential documents.
- **A query that gives the wrong answer**: open an *Evaluation case* issue with the query,
  the evidence policy and the pages that should or should not match.
- **An idea**: open a feature request, or check [`ROADMAP.md`](ROADMAP.md) first.
- **A question about usage**: read the [user guide](docs/user-guide.md) and
  [troubleshooting](docs/user-guide.md#troubleshooting), then open an issue with the
  `question` label.
- **A security concern**: see [`SECURITY.md`](SECURITY.md); do not open a public issue.

This is a personal open-source project maintained in spare time. Answers can take a few days.
